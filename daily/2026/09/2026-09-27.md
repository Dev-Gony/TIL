## 2. 고용24 AI 고용서비스 해커톤 아이디어 조사

추가 공모전 참가를 검토하면서

핵심 기준은 단순 챗봇보다

- 실제 공개 데이터 사용 가능성

- AI가 개입했을 때 개선되는 지점
- 데모와 평가 지표를 만들 수 있는지

를 먼저 보는 방향으로 잡았다.

## 3. AI 이미지 생성 전략 검토

블로그 자동화에서 글 생성과 이미지 생성을 한 서비스에 모두 맡기기보다
역할을 분리하는 방향을 검토했다.

### 비교한 방향

- Gemini API: 글 생성 중심
- Cloudflare FLUX 계열: 이미지 생성 테스트
- Gemini Web 자동화: 기존 Chrome 제어 구조를 이용한 이미지 생성 후보
- Genspark Plus: 병렬 이미지 작업 가능성 및 비용 검토

### 판단

하루 여러 글에 이미지가 여러 장씩 필요한 구조에서는
단일 이미지 품질뿐 아니라 **비용, 쿼터, 병렬 처리, 자동화 안정성**을 함께 봐야 했다.

Cloudflare 이미지 품질이 목표에 못 미치는 경우
API만 고집하지 않고 웹 기반 생성 흐름도 후보로 두기로 했다.
