# 2026-09-25 작업일지

## 오늘의 핵심

오늘은 사실상 **AFFIX: ZERO 집중 개발일**이었다.

전날 만든 Godot 프로토타입을 실제 게임처럼 보이게 만들기 위해
UI/UX, 밸런스, 엘리트/보상, 드랍 연출, 펫, 아이템 그래픽, 던전 전투까지 빠르게 확장했다.

하지만 저녁 실플레이에서 중요한 문제가 드러났다.

- 캐릭터/몬스터 애니메이션이 실제 게임 애니메이션처럼 보이지 않음
- 캐릭터 무기 공격 표현이 부자연스러움
- 펫이 기능과 비주얼 모두 완성품처럼 느껴지지 않음
- 원거리 공격, 드랍, 펫 가챠가 실제 시스템보다 목업처럼 보임
- 자동 테스트는 많이 통과했지만 **실제 플레이 품질은 통과하지 못함**

결과적으로 오늘의 가장 큰 성과는 기능 수가 아니라
**"테스트 PASS와 플레이 가능한 게임은 다르다"는 사실을 명확하게 확인한 것**이다.

GONY DAILY는 별도 기능 개발 없이 runtime state 갱신만 확인됐다.

## 7. 실플레이에서 드러난 실패

자동 테스트와 CI는 상당 부분 통과했지만
Windows 실플레이에서는 제품 품질 측면에서 명확한 문제가 확인됐다.

### 발견한 문제

- 캐릭터가 정지 원화 위에서 움직이는 것처럼 보여 실제 Animation 감각이 없음
- 몬스터도 Walk / Hit / Death가 자연스러운 Frame Animation으로 읽히지 않음
- 캐릭터 원화 위에 별도 검을 덧그리는 표현이 부자연스러움
- Pet Graphic / Follow / Attack이 임시 구현처럼 보임
- Ranged Combat이 Projectile 시스템이라기보다 효과만 붙인 것처럼 느껴짐
- Drop Feedback은 존재하지만 실제 Loot를 얻는 즐거움이 부족
- Pet Gacha를 실행해도 결과가 명확히 전달되지 않음

즉 **기능이 코드에 존재하는 것과 사용자가 기능을 인지하는 것은 완전히 다른 문제**였다.

## 오늘 배운 점

1. **자동 테스트 PASS는 게임 품질 PASS가 아니다.**
   - 로직과 저장이 맞아도 Animation, Hit Feel, Drop Feel이 나쁘면 게임은 완성된 것이 아니다.

2. **게임 기능은 '존재'가 아니라 플레이어가 인지할 수 있어야 한다.**
   - Pet Gacha는 API나 Button이 동작하는 것보다 결과가 명확히 보이는 것이 먼저였다.

3. **방치형 게임의 보스는 액션 패턴보다 성장 루프와 맞아야 한다.**
   - 수동 패턴 중심 Boss 설계를 폐기하고 파밍 → 성장 → 재도전 구조를 유지했다.

4. **큰 변경은 Draft PR로 격리하는 것이 안전하다.**
   - 하루 동안 방향이 여러 번 바뀌었지만 Main을 망가뜨리지 않고 비교할 수 있었다.

5. **비주얼 문제는 코드 Overlay로 숨길 수 없다.**
   - 정지 원화 위에 Weapon / Limb Effect를 얹는 방식은 실제 Frame Animation을 대체하지 못했다.
